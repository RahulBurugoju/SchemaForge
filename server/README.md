# SchemaForge — Backend Server

This directory contains the Express 5 + Node.js REST API backend for **SchemaForge** — Visual Database Modeling & DDL Generator.

For full project documentation, architecture overview, setup instructions, and complete API reference, please refer to the main [Root README.md](../README.md).

## Quick Start (Backend)

```bash
# Install dependencies
npm install

# Start Express server with nodemon
npm run server
```
