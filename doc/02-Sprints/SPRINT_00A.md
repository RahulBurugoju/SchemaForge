# Architecture Decisions

The following architectural decisions were finalized.

### Internal Schema

The canvas never generates SQL directly.

All export generators consume the Internal Schema Model.

---

### State Management

Redux Toolkit is the only global state manager.

React state handles local UI state.

---

### Folder Organization

Feature-Based Architecture.

---

### Routing

Nested layouts with protected routes.

---

### Documentation

Documentation is part of development.

A feature is incomplete until documentation is updated.
